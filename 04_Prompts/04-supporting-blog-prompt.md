# Prompt 4 – Supporting Blog Generation

## Prompt
```
Write a supporting blog of about {word_count} words.

Title: {title}
Target keyword: {keyword}
Pillar page to link to: {pillar_title}
Business: {business_name}, {area}, {city}
Tone: warm, helpful, local

Structure:
- H1 with keyword
- Short intro (2-3 sentences)
- 3-4 H2 sections with useful, practical tips
- A short FAQ (2-3 questions)
- CTA at the end

Rules:
- Link to the pillar page once in the intro and once near the end.
- Mention the area naturally 2-3 times.
- No made-up facts. Use [placeholders] for unknown details.
```
