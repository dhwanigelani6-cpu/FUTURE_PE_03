# Prompt 2 – SEO Blog Outline (H1–H3)

## Prompt
```
Act as an SEO content strategist.

Create a detailed blog outline.
Target keyword: {primary_keyword}
Secondary keywords: {secondary_keywords}
Search intent: {intent}
Business: {business_name}, {area}, {city}
Audience: {audience}

Requirements:
- One H1 containing the target keyword
- 5-7 H2 sections, with H3 subsections where helpful
- An FAQ section with 4 questions people actually search
- A local SEO section mentioning the area and a nearby landmark
- A closing CTA section
- Suggest a meta title (under 60 characters) and meta description (under 155 characters)

Output in markdown.
```

## Prompt Logic
- The outline is created before the article so structure matches search intent.
- Character limits for meta tags keep the output website-ready.
