# Prompt 3 – Pillar Blog Generation

## Prompt
```
You are a professional content writer for local businesses.

Using the outline below, write a long-form pillar blog of about {word_count} words.

Outline:
{paste_outline}

Business details:
- Name: {business_name}
- Location: {area}, {city}
- Highlights: {usps}

Writing rules:
- Friendly, simple language. Short paragraphs.
- Use the primary keyword naturally in the H1, first paragraph and one H2.
- Do not keyword-stuff.
- Do not invent facts, prices, awards or reviews. Use [placeholders] for unknown details.
- Add 3 internal link placeholders to supporting blogs like [LINK: rooftop cafe blog].
- End with a clear CTA (visit, call, get directions).
```

## Prompt Logic
- "Do not invent facts" keeps the content honest and publish-safe.
- Internal link placeholders connect directly to the cluster plan.
