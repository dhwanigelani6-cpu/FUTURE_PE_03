# Prompt 5 – Internal Linking Suggestions

## Prompt
```
Act as an SEO specialist.

Here is my content cluster:
- Pillar: {pillar_title} ({pillar_keyword})
- Supporting posts: {list_of_supporting_titles_and_keywords}

Task:
1. Suggest internal links from each supporting post to the pillar and to other relevant supporting posts.
2. For every link give: source page, target page, natural anchor text (3-6 words), and where in the article it should appear.
3. Avoid exact-match anchor text overuse.

Output as a markdown table.
```
