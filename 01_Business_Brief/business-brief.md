## Project Overview

This project is a structured AI prompt system that generates SEO-optimized blog content and a topical content cluster for a real local business.

It covers keyword research, search-intent mapping, blog outlines, long-form pillar content, supporting articles, internal linking and local SEO.

---

## Business Used

**The Beans & Beyond Cafe**
**Location:** Chandkheda, Ahmedabad, Gujarat

A vegetarian cafe offering coffee, beverages, food, desserts and multiple cuisines, with indoor, outdoor and rooftop seating, located near Zundal on Sardar Patel Ring Road.

---

## Project Objective

Build a reusable prompt workflow that can:

- Identify relevant SEO keywords
- Map keywords to search intent
- Generate SEO-friendly blog outlines (H1–H3)
- Write long-form pillar content
- Write supporting blog content
- Build a content cluster with internal links
- Adapt content for local SEO (city + service)
- Keep content helpful, readable and business-focused

---

## Workflow

Business Research → Keyword Research → Search Intent Mapping → Content Cluster Planning → Prompt Engineering → Pillar Blog → Supporting Blogs → Internal Linking → Local SEO → Final SEO Content Pack

---

## Tools Used

- ChatGPT / Claude (content generation)
- Google Search & Google Trends (keyword reference)
- GitHub (documentation)
- Markdown / Google Docs
